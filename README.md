## How I work

- **Find the real bottleneck first.** On Harf Arena it wasn't the game. It was keeping a steady supply of good clues, so the fix was a content pipeline rather than another feature.
- **Measure before arguing.** Every funnel gets named events, even when the only person I'm arguing with is me.
- **Write the rules before the marketing.** Each product has a brief listing what we may and may not claim. Mine bans invented download numbers, which is very annoying for someone trying to fill in a GitHub profile.
- **Cut things.** Sunk cost is not a feature.
- **Use AI agents as the build team.** I write the requirements, review the result and own the decisions. They write a lot of code and have never once asked for equity.
